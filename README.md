# .github

Shared issue templates for every GameRun-New repository.

GitHub uses the files in `.github/ISSUE_TEMPLATE/` here for any repository in the organization that has no `.github/ISSUE_TEMPLATE/` folder of its own. Edit a template here and every repository picks it up.

This repository is public because GitHub only serves shared templates from a public `.github` repository. Keep it to the templates.

Do not add a `.github/ISSUE_TEMPLATE/` folder to another repository. One file there switches that repository off the shared set.
